# Analytics and observability

`@chromawave/analytics` defines a discriminated event map. Cycle one uses a local
development logger/no-op adapter.

Tracked flow events are onboarding completion, capture start/completion,
palette extraction, pairing request/acceptance, Memory save, and Memory detail
open. Atelier adds screen open, Collection creation/membership changes, Monthly
Recap and Palette Lab views, Memory remix, and share intent. Properties are IDs
generated by the app, counts, durations, moods, formats, and provider names. Raw
photos, URIs, notes, location, collection names, and search text are forbidden.

Errors use stable codes and safe context. Sentry is an integration point only;
without a DSN there is no network transport.
