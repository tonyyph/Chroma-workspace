# Definition of done

A vertical slice is done only when:

- Domain and external input are strictly typed and validated.
- Real local image selection and palette extraction work; no hard-coded palette.
- The music provider is clearly identified as mock.
- A confirmed photo is durably copied and the Memory survives relaunch.
- Timeline and detail use the repository, not duplicated sample state.
- Loading, empty, failure, offline, and denied-permission states are reachable.
- Dynamic color, screen reader, touch target, and reduced-motion rules are applied.
- Typecheck, lint, unit/component tests, formatting, and Expo config pass.
- A simulator/device launch is attempted and the result is reported honestly.
- Limitations and next risks are documented; placeholders are not called complete.
