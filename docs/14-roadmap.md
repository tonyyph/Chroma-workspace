# Roadmap

## M0 - Foundation (current)

Monorepo, strict TypeScript, checks, docs, domain schemas, tokens, provider
boundaries, and mobile shell.

## M1 - Local-first premium vertical slice (current)

Editorial onboarding, camera and library capture, preview, local perceptual palette
extraction, confirmation, mock pairing, local save, Today insights, searchable and
filterable Archive, durable favorites, and immersive Memory detail.

## M2 - Real pairing

Spotify OAuth, adapter, recommendation ranking, preview lifecycle, search, and
re-pairing.

## M3 - Cloud and discovery

Supabase auth/storage/RLS, sync queue, collections, public projection, discovery,
reporting, and public web pages.

## M4 - Monetization and beta

RevenueCat, centralized enforcement, exports, observability, accessibility and
performance audits, store assets, and TestFlight/internal beta.
